Hushline: an original top-down stealth game. Slip through a lantern-lit estate past keepers whose vision cones swing and brighten as suspicion rises, cameras sweeping their blind spots, an awareness meter filling when you are seen and cooling when you hide. Three floors, a key to find, a loot grab and an exit that rewards patience; crouch to shrink your light and stay out of the warm cones. Built by an AI agent for make.fun's "Make the best stealth game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
